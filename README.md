# Кто выгуливает Бориса

Одностраничный сервис для сотрудников вымышленной компании «Догяндекс»: запись на прогулку с офисным псом Борисом и отметка о его кормлении. Страница общая, без авторизации. Сотрудник видит слоты на сегодня, выбирает свободный, вводит имя и фамилию и записывается. Учебный micro-MVP, все данные синтетические.

## Возможности

- Показ текущей даты и пяти фиксированных слотов прогулок: `09:00`, `11:00`, `13:00`, `15:00`, `17:00`.
- Запись на свободный слот по имени и фамилии. Занятый слот показывает, кто гуляет, и не даёт записаться повторно.
- Серверная защита от двойной записи: повторная попытка занять слот возвращает понятный отказ, первая запись не меняется.
- Хранение состояния в SQLite: записи сохраняются после обновления страницы, перезапуска сервера и видны из другого браузера.
- Дополнительно: карточка «Последнее кормление» в формате «Сегодня, 15:09 • Илья Примеров» и кнопка «Покормили Бориса» с полем для имени и фамилии.
- Работа на широком и узком экране.

## Технологии

- Node.js 22.13 или новее (проверено на Node.js 24) и npm.
- SQLite через встроенный модуль `node:sqlite`, без сторонних драйверов.
- Сервер на встроенном модуле `node:http`, страница на чистых HTML, CSS и JavaScript.
- Шрифты Handjet и IBM Plex Mono подключаются из Google Fonts. Без интернета страница работает, но со стандартным моноширинным шрифтом.
- Без фреймворков, внешних сервисов, API-ключей и деплоя.

## Быстрый запуск

Потребуется Node.js 22.13 или новее. Устанавливать зависимости не нужно.

```bash
npm start
```

В терминале появится строка `Борис ждёт на http://localhost:3000`.

## Запуск

Откройте http://localhost:3000 в браузере. При первом запуске в папке проекта создаётся файл `boris.sqlite`, а в нём пять свободных слотов на текущую дату. На каждый новый день слоты создаются автоматически при первом открытии страницы.

Порт и путь к базе можно поменять через переменные окружения:

```bash
PORT=4000 DB_PATH=./other.sqlite npm start
```

Остановить сервер: `Ctrl+C` в терминале.

Проверка главного сценария:

1. Выбрать свободный слот, ввести «Анна Тестова», нажать «Выбрать». Слот становится занятым и показывает «Гуляет: Анна Тестова».
2. Во втором браузере попробовать занять тот же слот. Сервер отказывает: «Слот 11:00 уже занят: с Борисом гуляет Анна Тестова. Выберите другое время». Исходная запись остаётся.
3. Обновить страницу или открыть её во втором браузере. Состояние то же.
4. В карточке кормления ввести «Илья Примеров» и нажать «Покормили Бориса». Карточка показывает новое время и имя.
5. Повторить сценарий в узком окне.

## Структура проекта

```text
ai-tools-for-pdm/
├── public/
│   ├── index.html   — разметка страницы
│   ├── style.css    — стили, широкий и узкий экран
│   └── app.js       — загрузка состояния, запись на слот, отметка кормления
├── server.js        — HTTP-сервер, API и работа с SQLite
├── package.json     — команда npm start
├── boris.sqlite     — база, создаётся при первом запуске (в .gitignore)
├── spec.md
├── README.md
├── AGENTS.md
└── PLAN.md
```

API:

- `GET /api/state` — текущая дата, пять слотов и последнее кормление.
- `POST /api/slots/book` с `{ "time": "11:00", "name": "Анна Тестова" }` — запись на слот. Если слот занят, сервер отвечает `409`.
- `POST /api/feedings` с `{ "name": "Илья Примеров" }` — отметка кормления.
